# Dicee Game

A simple browser-based dice game where two players roll dice and the winner is announced on screen.

## Preview

![Dice game preview](./assets/dice_6.png)

This project shows the classic dice game layout with two dice, a winner message, and a purple theme.

## How to run

1. Open the project folder in your browser.
2. Open `index.html` in a browser.
3. Refresh the page to roll the dice again.

## Files

- `index.html` – page structure
- `styles.css` – styling
- `main.js` – dice logic and winner decision
- `assets/` – dice images

## Gameplay

- Each player gets a random dice value.
- The page updates both dice images.
- A message shows whether Player 1, Player 2, or neither wins.
